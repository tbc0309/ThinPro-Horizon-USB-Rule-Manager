# 故障排查

## USB 列表没有设备

- 确认设备直接插在 ThinPro 上。
- 更换 USB 接口并重新扫描。
- 使用 `lsusb` 检查系统是否识别设备。

## 添加后 Horizon 仍无法连接

- 物理拔插设备。
- 完全退出 Horizon 桌面会话后重新连接。
- 确认 Horizon Agent 或服务端策略允许 USB 重定向。
- 检查设备是否同时被 RTAV、音频重定向或其他程序使用。

## Windows 设备管理器能看到，业务软件不能识别

此时 ThinPro 到 Windows 的 USB 通道通常已经成功。继续检查：

- Windows 是否加载正确的厂商或 UVC 驱动；
- 设备是否有黄色叹号；
- Windows 相机或其他基础测试程序能否访问设备；
- 业务软件是否只支持指定驱动、DirectShow 接口或设备版本。

## SSH 主机指纹改变

系统重装会生成新的 SSH 主机密钥。确认 IP 对应正确设备后，再接受新指纹。无法确认时不要继续连接。

## 恢复配置

选择“恢复首次原始状态”，并输入大写 `RESTORE`。工具会使用 ThinPro 同级首次备份恢复 `/etc/vmware/config`，并按首次状态恢复或删除托管规则文件。
